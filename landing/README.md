# Virgule landing page

Static, dependency-free landing page for the Virgule Mac app (the repository is `ayushmk7/Virgule`; source paths still use the NativeLatex name; media files and the `libreweave-theme` storage key keep their old names on purpose). The app builds and runs locally but is not Developer ID signed or notarized, so there is no public download: the single Explore action links to the repository. The hero is text only (headline, lede, Explore) at full viewport height, with a bouncing "Scroll" cue (the Website's chevron) that jumps to the demo below. The demo section is the second screen: only the video, sized to fit the viewport in both width and height (caption kept for screen readers only). It plays a looping, muted video of the real app (`media/`; how it was made: [Brag workspace](../docs/workspaces/brag/README.md)). Native video controls let visitors turn on sound. Copy only describes what `main` does today (one file per window, local TeX builds, Pandoc-based Markdown preview); see the facts table in [docs/status.md](../docs/status.md). Replace the Explore action with a download only after a signed and notarized build passes the [deployment gate](../docs/deployment-plan.md).

## Look

Matches the owner's Website and Internship pages: white/black surfaces, system sans type, open spacing, pill buttons, BB-8 switch in the top-right corner. The one brand blue is the Website base theme's `#2563EB` in both appearances; in dark mode all non-blue text is pure white. Section dividers are removed. Sections have headings only, no eyebrow labels or step numbers. `icon.svg` is owned by Art and generated by `art/tools/gen.py`.

The theme switch is the same BB-8 toggle those two sites use. `bb8.css` is the Website's `src/components/pro/opt4/bb8.css` (artwork by Galahhad on Uiverse.io, MIT) with the artwork unchanged, its orange variable renamed `--bb8-accent` to reserve `--accent` for brand blue, and ten hover rules added for the head and antennae; `styles.css` only sizes it, outlines it, and keeps its checkbox keyboard-focusable. The Mac app draws the same toggle natively in SwiftUI (`NativeLatex/Design/Sources/NativeLatexDesign/BB8Toggle.swift`); the two are kept in step by eye, not shared code.

## Local preview

From the repository root, run `python3 -m http.server 4173 --directory landing` and open `http://localhost:4173`.

## Deployment

GitHub Pages is the live deployment at <https://virgule.ayushmadhav.com/> (HTTPS enforced; CNAME to `ayushmk7.github.io` in Vercel DNS), published from `landing/` by `.github/workflows/pages.yml`. The old host `libreweave.ayushmadhav.com` was retired on 2026-11-18 at the owner's request: its Vercel redirect project and DNS record are deleted, so old links no longer resolve to the page. The page itself is not hosted on Vercel. Vercel Hobby is for personal, non-commercial use; check the [deployment plan](../docs/deployment-plan.md) before moving the page there.
