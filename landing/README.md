# LibreWeave landing page

Static, dependency-free landing page for the LibreWeave Mac app (repository and paths still use the NativeLatex name). The app builds and runs locally but is not Developer ID signed or notarized, so there is no public download: the page links to the repository, says so in the hero badge, and labels the app window as a concept illustration. Copy only describes what `main` does today (one file per window, local TeX builds, Pandoc-based Markdown preview); see the facts table in [docs/README.md](../docs/README.md). Replace the GitHub call to action with a download only after a signed and notarized build passes the [deployment gate](../docs/deployment-plan.md).

## Look

Matches the owner's Website and Internship pages: white/black surfaces, system sans type, hairline dividers, pill buttons, BB-8 switch in the top-right corner. Neutrals are the Internship/Apple greys. The blue is the Website's (`src/pages/index.astro`, `body.opt7`): `#0F2BFF` for text and fills in light mode (7.47:1 on white, and with white text), `#2438FF` for fills in dark mode (white text 6.81:1) and `#7A93FF` for blue text on black (7.45:1). Under `prefers-contrast: more` only the greys and dividers get stronger. Sections have headings only, no eyebrow labels. `icon.svg` is owned by Art and generated by `art/tools/gen.py`.

The theme switch is the same BB-8 toggle those two sites use. `bb8.css` is the Website's `src/components/pro/opt4/bb8.css` (artwork by Galahhad on Uiverse.io, MIT) with the artwork unchanged, its header comment replaced and ten hover rules added for the head and antennae (see the comment at the top of the file); `styles.css` only sizes it, outlines it, and keeps its checkbox keyboard-focusable. The Mac app draws the same toggle natively in SwiftUI (`NativeLatex/Design/Sources/NativeLatexDesign/BB8Toggle.swift`); the two are kept in step by eye, not shared code.

## Local preview

From the repository root, run `python3 -m http.server 4173 --directory landing` and open `http://localhost:4173`.

## Deployment

GitHub Pages is the deployment (default URL <https://ayushmk7.github.io/NativeLatex/>), published from `landing/` by `.github/workflows/pages.yml`. Custom domain `libreweave.ayushmadhav.com` is configured in GitHub Pages settings and in Vercel DNS (CNAME to `ayushmk7.github.io`), but its HTTPS certificate is still pending, so it is not verified live yet. Vercel hosting is optional and not connected: import the repository with **Root Directory** `landing` and framework **Other** (no build command). Vercel Hobby is for personal, non-commercial use; check the [deployment plan](../docs/deployment-plan.md) first.
