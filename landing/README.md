# LibreWeave landing page

Static, dependency-free landing page for the LibreWeave Mac app (repository and paths still use the NativeLatex name). The app builds and runs locally but is not Developer ID signed or notarized, so there is no public download: the page links to the repository, says so in the hero badge, and labels the app window as a concept illustration. Copy only describes what `main` does today (one file per window, local TeX builds, Pandoc-based Markdown preview); see the facts table in [docs/README.md](../docs/README.md). Replace the GitHub call to action with a download only after a signed and notarized build passes the [deployment gate](../docs/deployment-plan.md).

## Look

Matches the owner's Website and Internship pages: white/black surfaces, system sans type, hairline dividers, pill buttons, BB-8 switch in the top-right corner. Neutrals are the Internship/Apple greys the app's `Theme.swift` also uses. The two reference sites use different blues (Internship `#0066CC`/`#0A84FF`, Website `#0F2BFF`/`#7A93FF`), so the page keeps the app and icon brand blue: royal `#4169E1` for fills and light-mode text (4.85:1), `#8BA6FF` for text on black (9.0:1), and the app's Increase Contrast values (`#1E3FB8`, `#2F55D4`, `#B4C6FF`) under `prefers-contrast: more`. `icon.svg` is owned by Art and generated by `art/tools/gen.py`.

The theme switch is the same BB-8 toggle those two sites use. `bb8.css` is copied verbatim from the Internship frontend (artwork by Galahhad on Uiverse.io, MIT); `styles.css` only sizes it, outlines it, and keeps its checkbox keyboard-focusable. The Mac app draws the same toggle natively in SwiftUI (`NativeLatex/Design/Sources/NativeLatexDesign/BB8Toggle.swift`); the two are kept in step by eye, not shared code.

## Local preview

From the repository root, run `python3 -m http.server 4173 --directory landing` and open `http://localhost:4173`.

## Deployment

GitHub Pages is the live deployment (<https://ayushmk7.github.io/NativeLatex/>), published from `landing/` by `.github/workflows/pages.yml`. Vercel is optional and not connected: import the repository with **Root Directory** `landing` and framework **Other** (no build command). Vercel Hobby is for personal, non-commercial use; check the [deployment plan](../docs/deployment-plan.md) first.
