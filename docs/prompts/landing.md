# Landing workspace brief

Maintain the static `landing/` page using `docs/workspaces/landing/landing-plan.md`, the Downloads frontend design guide, and the user's Website BB-8 toggle as visual references. Keep the page black/white with exactly one brand blue, `#2563EB` from the Website base theme, in the app, icon and landing. Use neutral white for small dark-mode text that would otherwise fail contrast. The demo must show actual app behavior, and the call to action must point to the project while no signed Mac release exists. Test desktop and narrow viewports, theme persistence, reduced motion, playback, and local links. Work on the Landing branch; GitHub Pages publishes the page on push to main.
