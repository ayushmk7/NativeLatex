# Backend workspace brief

Use `docs/workspaces/backend/architecture.md` to build the Mac-only Swift app core. Keep ordinary files in place, save without losing external edits, dispatch `.tex` to local `latexmk` and `.md` to local preview, and show PDF/log/diagnostics without a server. Run real one-file and multi-file builds and a missing-TeX check. Keep build output and cancellation scoped to each window. Use `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer` on this Mac. Work on the Backend branch; do not sign, publish, or merge until the app passes the documented gates.
