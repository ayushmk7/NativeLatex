# UX workspace brief

Use `docs/workspaces/ux/ux-plan.md` to implement the native Mac window and file flows. Support several folder workspaces, direct Finder opens, source/preview split, problems/log, keyboard access, VoiceOver, and app-wide System/Light/Dark appearance. The BB-8 control changes appearance without hiding the standard Settings/View path. Test narrow windows, external-file changes, Reduce Motion, and Increase Contrast. Work on the UX branch and report concrete user-flow checks before merging.
