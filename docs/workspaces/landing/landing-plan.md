# Landing workspace plan

Status: live on GitHub Pages at <https://ayushmk7.github.io/NativeLatex/> · 2026-11-17

The landing page is a single static page in [`landing/`](../../../landing/README.md), deployed to GitHub Pages by `.github/workflows/pages.yml`; Vercel remains an unconnected alternative with that directory as the project root. It uses no framework, build service, account, analytics, or form. While no signed Mac release exists, its main action links to the GitHub project and clearly says there is no download. The window graphic is labeled as a concept preview.

The visible product name is **LibreWeave**; the repository keeps the NativeLatex name. The look follows the owner's Website and Internship pages (black/white, system sans, hairlines, pill controls, BB-8 in the top-right corner). Neutrals use the Internship/Apple greys shared with the app's `Theme.swift`. The reference sites use different blues (Internship `#0066CC`/`#0A84FF`, Website `#0F2BFF`), so the page keeps the app and icon brand royal blue `#4169E1` (`#8BA6FF` as text on black) plus the app's Increase Contrast values. Copy describes only what `main` does today: one file per window, local TeX builds, Pandoc Markdown preview, and no public download because the app is not Developer ID signed or notarized. The theme switch reuses the exact Uiverse BB-8 toggle shipped on both of those sites, with its MIT credit; the Mac app still needs its own original native switch under the [art plan](../art/art-direction.md). The favicon and header mark come from the Art branch's small-size icon master.

Before publishing: recheck the app name, preview both themes at desktop and narrow widths, test keyboard/screen-reader switch behavior, Vercel is optional: connect the repository with `landing` as Root Directory and **Other** as framework only if the owner chooses it over Pages. No download button or release claim appears until a signed and notarized artifact passes the [deployment gate](../../deployment-plan.md).
