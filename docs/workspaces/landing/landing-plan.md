# Landing workspace plan

Status: live on GitHub Pages at <https://ayushmk7.github.io/NativeLatex/> (serves `main`; `landing` branch changes appear after merge) · 2026-11-17

The landing page is a single static page in [`landing/`](../../../landing/README.md), deployed to GitHub Pages by `.github/workflows/pages.yml`; Vercel remains an unconnected alternative with that directory as the project root. It uses no framework, build service, account, analytics, or form. While no signed Mac release exists, its main action links to the GitHub project and clearly says there is no download. The window graphic is labeled as a concept preview.

The visible product name is **LibreWeave**; the repository keeps the NativeLatex name. The look follows the owner's Website and Internship pages (black/white, system sans, hairlines, pill controls, BB-8 in the top-right corner). Neutrals use the Internship/Apple greys. The blue is the Website's `body.opt7` blue from `src/pages/index.astro`, at the owner's request: `#0F2BFF` for text and fills in light mode, `#2438FF` for fills and `#7A93FF` for text in dark mode. This differs from the app and icon royal blue `#4169E1`. Under `prefers-contrast: more` only the greys and dividers strengthen. Sections carry headings only, with no eyebrow labels. Copy describes only what `main` does today: one file per window, local TeX builds, Pandoc Markdown preview, and no public download because the app is not Developer ID signed or notarized. The theme switch reuses the exact Uiverse BB-8 toggle shipped on both of those sites, with its MIT credit. The Mac app has its own native SwiftUI version, `NativeLatex/Design/Sources/NativeLatexDesign/BB8Toggle.swift`, linked into the app's toolbar; the two are matched by eye, not shared code. `landing/icon.svg` is owned by Art and generated by `art/tools/gen.py`.

## Verified state (on main `ce50a3e` plus the Website-blue change, 2026-11-17)

Headless Chrome via `playwright-core` against `python3 -m http.server`, at 1440×900 and 390×844, system light and dark:

- Initial theme follows the system and the BB-8 knob matches it before first paint; Space on the focused switch flips the theme; the choice persists across reload; live system appearance changes are followed until the visitor picks a theme, then ignored.
- No horizontal overflow at either width, before or after toggling. The switch's tap area is 71×45 px at 390 px.
- Switch is reachable by Tab (after skip link, brand, three nav links) and shows a `#0F2BFF` focus ring (`#7A93FF` in dark mode); reduced motion still toggles; `prefers-contrast: more` (emulated) applies the stronger greys in both themes. Computed colors confirm the heading accent and primary button use `#0F2BFF` in light mode and `#7A93FF`/`#2438FF` in dark mode, and no `.eyebrow` element remains.
- In-page anchors resolve; both GitHub links return HTTP 200; no console errors or failed requests; visible text says LibreWeave only and has no download call to action.
- Computed contrast of every text pair in use is ≥ 4.66:1 (muted grey on the light panel). Blue: `#0F2BFF` on white 7.47:1, white on `#0F2BFF` 7.47:1, `#7A93FF` on black 7.45:1, white on `#2438FF` 6.81:1.

Not yet done: a VoiceOver pass on the switch (markup is a native checkbox with `role="switch"` and `aria-label="Dark mode"`, but no screen reader was run), and checks in Safari and Firefox.
